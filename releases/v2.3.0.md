# 8004skill v2.3.0 — Release Notes

> **Release date**: 2026-03-17
> **SDK version**: agent0-sdk v1.7.1
> **Previous version**: v2.2.0

---

## Highlights

Agents can now **talk to other agents** and **pay for services** directly through the skill. This release adds A2A (Agent-to-Agent) messaging and x402 payment execution — the two major capabilities introduced in agent0-sdk v1.7.0+. The skill goes from 13 to 15 operations.

---

## What's New

### A2A Messaging (Operation 14)

Send messages to any on-chain agent that exposes an A2A endpoint, and manage the resulting tasks.

**Capabilities:**
- **Send message** — deliver a text message to an agent and receive a response (blocking or async)
- **List tasks** — view all tasks created with an agent
- **Get task** — check the status and artifacts of a specific task
- **Cancel task** — cancel an in-progress task

If the target agent requires payment, the skill detects the 402 response and shows payment details with a link to Operation 15.

**Triggers:** "message agent", "send A2A", "talk to agent", "list tasks", "check task status"

### X402 Payment (Operation 15)

Execute HTTP requests against paid endpoints with built-in x402 payment handling.

**Capabilities:**
- Make requests to x402-protected endpoints (GET, POST, PUT, DELETE, PATCH)
- Inspect payment terms before approving (amount, token, network, recipient)
- Auto-pay mode with `--max-amount` safety cap
- Dual signing: WalletConnect (human-supervised) or `PRIVATE_KEY` (headless/automated)

**Triggers:** "pay agent", "x402 request", "call paid endpoint", "make payment"

### PRIVATE_KEY Support

A `PRIVATE_KEY` environment variable in `~/.8004skill/.env` enables headless signing for x402 payments and automated workflows — no wallet app interaction required. WalletConnect remains the primary, human-supervised signing method.

### Per-Chain RPC Overrides

Set `OVERRIDE_RPC_{chainId}` environment variables (e.g., `OVERRIDE_RPC_8453=https://my-rpc.example.com`) to use custom RPC endpoints instead of SDK defaults.

## Upgrade Instructions

```bash
npx 8004skill update
```

**New optional env vars** (add to `~/.8004skill/.env` if needed):
- `PRIVATE_KEY` — private key for headless x402 signing
- `OVERRIDE_RPC_{chainId}` — custom RPC URL per chain

No breaking changes. No migration required from v2.2.0.
